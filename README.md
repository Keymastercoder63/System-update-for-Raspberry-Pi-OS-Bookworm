System-update is a APT, NPM and PIPX updater Bash script. It's only one file but can has a pre-included Desktop entry file if you want to just have a 2-click launcher and thats it no distractions just a Updater. Target: Raspberry Pi OS Bookworm (English). Checks if packages are outdated for apt and npm but just updates pipx and flatpak Packages. also zip file for download.
